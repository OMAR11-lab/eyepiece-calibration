How the objective lens changes eyepiece graticule calibration

The graticule is fixed inside the eyepiece. The stage micrometer is a real scale. Switch objective lens and watch how many graticule units fit into 100 µm.

Calibration formula

1 graticule unit (µm) = stage micrometer length (µm) ÷ graticule units it spans

Key points

  • Low power: 100 µm looks small, so many units span it and each unit is a larger real distance.
  • High power: 100 µm looks large, so few units span it and each unit is a smaller real distance.
  • Calibrate again every time you change the objective lens.
  • Real size = number of graticule units counted × calibration for that objective.

Example values assume a ×10 eyepiece. Calibrate your own microscope with its own stage micrometer.
